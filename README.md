# Thí nghiệm tìm CUTOFF tối ưu cho Mergesort

Project môn Cấu trúc dữ liệu và giải thuật (UET): đo thực nghiệm để tìm độ dài CUTOFF
chuyển sang insertion sort cho mergesort tự cài đặt từ bài giảng, và so sánh hai giá trị 7 và 10.

## Cấu trúc thư mục

| Thư mục | Nội dung |
| --- | --- |
| src/ | Merge.java, MergeCount.java, test, harness đo |
| data/ | Bộ dữ liệu thí nghiệm và manifest.csv (seed, SHA-256) |
| results/ | CSV thô, machine.txt, log |
| scripts/ | Script sinh dữ liệu, chạy thí nghiệm, phân tích |
| figures/ | Đồ thị |
| tables/ | Bảng thống kê |
| report/ | Báo cáo |

Hướng dẫn chạy lại thí nghiệm: sẽ cập nhật ở bước đóng gói.
