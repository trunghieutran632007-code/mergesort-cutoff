# Bảng C: doubling test (TN5, random)

- T: median thời gian một lần sort (ms). Tỉ lệ doubling = T(N) / T(N/2).
- Tỉ lệ lý thuyết nếu T ~ N log₂N: N log₂N / ((N/2) log₂(N/2)). Nếu T ~ N^b thì tỉ lệ = 2^b.
- Độ dốc log-log (bình phương tối thiểu của log₂T theo log₂N): cutoff 0: 1.079, cutoff 7: 1.085, cutoff 10: 1.088, cutoff 40: 1.092.
