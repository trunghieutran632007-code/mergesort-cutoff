# Bảng F: insertion sort so với mergesort trên mảng ngắn (TN4)

- Thời gian một lần sort (ns, median). merge = Merge.sort(a, 0): mỗi lần gọi cấp phát mảng aux mới; insertion = Merge.insertionSort(a, 0, n−1).
- Tỉ lệ = median của merge / insertion tính trong từng trial [CI 95% của median]. Tỉ lệ < 1: merge nhanh hơn.
- Bảng .md chỉ liệt kê một số n; file .csv có đủ mọi n đã đo.
- Điểm giao nhau: tỉ lệ xuống dưới 1 lần đầu ở n = 192 (n đo ngay trước: 160); nội suy tuyến tính giữa hai điểm này: n ≈ 187.
